## Non-integrated resources and retrieval failures

PharmGKB host resolution failed from the project environment; several guessed ClinPGx REST routes returned 404 and were not used. CPIC's documented API was reachable and used instead. Other reconnaissance resources (including Open Targets, Ensembl, GWAS Catalog, IMPPAT, LOTUS and DisGeNET) are not represented as integrated datasets unless an attributable cached record above exists. The ClinVar record here is a molecular identity cross-reference; its cached germline classification ('Likely benign; other', not-specified trait) is a disease-association label, not a drug-response classification, and it is displayed as such.
